# Notes From a Passive-Aggressive Fridge

[![make.fun](https://make.fun/badge/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7.svg)](https://make.fun)

## About

A one-line note a smart fridge leaves for its owner, written for [make.fun](https://make.fun)'s "Notes From a Passive-Aggressive Fridge" bounty.

The entry program (`main.ts`) writes the note to `/output/entry.txt`:

> I made 312 ice cubes this week. You used six. I am beginning to think you keep me around for the light.

Smug sensor count up front, petty grudge in the middle, and the sting lands on the last beat: maybe the owner only keeps the fridge around for the light.

## Run

```sh
node main.ts
```
